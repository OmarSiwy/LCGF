# References and research provenance

Research date: **2026-11-23**. Source audit pinned to [`ed94db3da27882ef1c87d0dd15a382b4df39e2c2`](https://github.com/OmarSiwy/LCGF/tree/ed94db3da27882ef1c87d0dd15a382b4df39e2c2).

Repository facts were checked against source. External references are primary specifications, official project documentation, original author publications, or a directly involved participant's summary. Recommendations and priorities are our engineering judgment; citing a reference does not mean that framework uses the proposed LCGF API.

The inventory references capability semantics, not wholesale implementation copying. CSS module numbers are not maturity ratings. Living `/TR/` and vendor URLs can change after the research date. The CSS Snapshot distinguishes mature and developing modules; a working draft or editor's draft must not be presented as a final interoperable contract. The Design Tokens Community Group format is a community specification, not a W3C Recommendation.

## Muratori material and access limits

The original lecture landing page and related API-design articles were readable. The reconstructed 2004 recording and the 2005 IMGUI recording were not fully retrievable in this environment; no full viewing or verified transcript is claimed. Handmade Hero chapter guides were used as indexes. Chris Hecker's API Design summary was available in the search index while the live page returned a temporary-down response. See [API design](api-design.md) for the exact application and attribution limits.
