# Dependency licence audit

The framework's own source is under its [MIT licence](../../LICENSE). Build dependencies are pinned by hash in [build.zig.zon](../../build.zig.zon). The package distributes source, shader outputs and font fixtures. Applications that select a native archive or ship a separate benchmark executable have a different set of third-party notices.

| Input or optional component | Verified terms and location | Distribution context |
|---|---|---|
| Unicode Character Database 16.0.0 | The UCD release's `ReadMe.txt` points to the Unicode terms. Retain the Unicode copyright and permission notice with redistributed data or its documentation. [Unicode licence](https://www.unicode.org/license.txt) | Host generation of text tables, plus conformance data in development builds. |
| HarfBuzz 13.2.1 | The archive's `COPYING` identifies the Old MIT licence and additional per-directory terms. In particular, `src/ms-use/COPYING` carries Microsoft's MIT notice. [Pinned release](https://github.com/harfbuzz/harfbuzz/releases/tag/13.2.1) | The optional shaper compiles HarfBuzz sources. Preserve applicable source notices with redistributions. |
| wgpu-native v27.0.4.1 and v29.0.1.1 | Both upstream manifests identify MIT OR Apache-2.0. All ten configured archives contain the corresponding tag in `wgpu-native-meta/wgpu-native-git-tag` and a BSD-3-Clause notice in `include/webgpu/webgpu.h`. The archives do not contain a consolidated dependency licence bundle. [v27 manifest](https://github.com/gfx-rs/wgpu-native/blob/v27.0.4.1/Cargo.toml), [v29 manifest](https://github.com/gfx-rs/wgpu-native/blob/v29.0.1.1/Cargo.toml) | Selecting the native renderer links a prebuilt static library. A binary distributor must collect notices for its linked dependency set as well as the public headers. |
| Vulkan-Headers 1.4.341.0 | `LICENSE.md` and `LICENSES/` distinguish file-specific Apache-2.0 and MIT licensing. The consumed `include/vulkan/vulkan_core.h` identifies Apache-2.0. [Pinned headers](https://github.com/KhronosGroup/Vulkan-Headers/tree/vulkan-sdk-1.4.341.0) | Build-time header translation. The platform supplies the loader and driver. |
| AccessKit C 0.23.2 | The archive README identifies MIT OR Apache-2.0 and the BSD-style Chromium notice in `LICENSE.chromium`. It identifies LGPL-2.1 for the Meson build system. The three library licence files are present in the archive. [Pinned release](https://github.com/AccessKit/accesskit-c/releases/tag/0.23.2) | A selected accessibility bridge can link the prebuilt static archive. Carry the applicable notices with the binary. |
| CLDR 49 core, numbers-full and dates-full | Each npm archive has a `LICENSE` and identifies Unicode-3.0 for data. The file separately describes the LDML specification. [CLDR JSON](https://github.com/unicode-org/cldr-json) | Test oracle for the hand-written locale implementation. |
| Liberation Sans and Noto subsets | The four fixture directories contain OFL 1.1 notices and original author information. The generation scripts identify each source and subset. [OpenType](../../src/text/font/testdata/OFL.txt), [shaping](../../src/text/shape/testdata/OFL.txt), [layout](../../src/text/layout/testdata/OFL.txt), [fallback](../../src/text/fallback/testdata/OFL.txt) | Distributed font fixtures and tests. Preserve the notices, reserved-name restrictions and authorship when redistributing or regenerating them. |
| Clay 0.14, Dear ImGui 1.93.0 and LVGL 9.6.0 | The pinned archives contain `LICENSE.md` (zlib), `LICENSE.txt` (MIT) and `LICENCE.txt` (MIT), respectively. LVGL's `COPYRIGHTS.md` maps its bundled third-party components to their individual terms. | Standalone comparison harnesses. The framework package links none of these benchmark implementations. |
| egui, Iced, Slint and Qt Quick comparisons | Pinned crate manifests identify MIT OR Apache-2.0 for egui 0.37, MIT for the Iced 0.14 crates, and GPL-3.0-only OR the Slint Royalty-free 2.0 OR Slint Software 3.0 licence for Slint 1.18.1. The Qt harness uses the platform-provided Qt distribution selected by Nix; use that distribution's module-specific notices. [Harnesses](../../bench/vs), [Qt licensing](https://doc.qt.io/qt-6/licensing.html) | Executable benchmark dependencies. Their distribution and font choices concern the particular harness built. |
| System APIs and development tools | Apple and Windows SDKs, system fontconfig, native graphics loaders and window systems are supplied by the platform. Naga and the Nix conformance tools are used to regenerate, validate or measure artifacts. [Dependency roles](../DEPENDENCIES.md), [pinned environment](../../flake.lock) | SDK and driver redistribution follows the platform's distribution terms. The library package contains no copy of those SDKs, tool executables or drivers. |

For a dependency update, verify its archive hash, inspect the changed licence files and file headers, and update this table alongside the dependency. For a published prelinked binary, record the selected backend, archive version, bundled files and notices for that binary. The source package and an application that statically links multiple native libraries have different inventories.
