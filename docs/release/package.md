# Using the Zig package

Use the compiler in `build.zig.zon` or the pinned Nix shell. Fetch an archive or Git revision you have pinned as a dependency, then import its modules in the application's build script.

```zig
const gui = b.dependency("lcgf", .{
    .target = target,
    .optimize = optimize,
    .render = .sw,
    .lanes = @as(u32, 4),
    .@"fixed-point" = false,
});
app.root_module.addImport("lcgf", gui.module("lcgf"));
app.root_module.addImport("lcgf_render", gui.module("lcgf_render"));
```

| Package option | Effect |
|---|---|
| `target`, `optimize` | Compile the modules for the consuming application's target and optimization mode. Unicode tables are generated by a host tool. |
| `render` | `auto` selects the target backend. Explicit choices are `sw`, `vk`, `metal`, `d3d12`, `gles`, `web`, and `wgpu`. Read `lcgf_render.kind` or `lcgf_render.Renderer` from the selected module. |
| `wgpu-native` | Select `v27` or `v29` for the wgpu binding. Available archives cover x86-64 and AArch64 macOS and Linux, and x86-64 Windows. |
| `lanes` | Override the target SIMD width with a supported power of two. Use one consistent width when sharing a column layout across modules. |
| `fixed-point` | Quantize the bare-metal software renderer's rectangle and clip coordinates to Q12.4. Defaults to false. |

The optional renderer module links its own backend inputs. Platform handles are backend-specific. Build-only flags such as `-Dno-float` for the fixed firmware example and `-Dweb-optimize` for web demonstrations belong to the repository build. Run `zig build --help` in the source checkout for its jobs and options.
